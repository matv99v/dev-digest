# specs — client

A spec per feature scoped to `@devdigest/web`, written **before** it is built. A feature
that also changes the API belongs in the root `../../specs/` instead.

Name files `NN-short-name.md`. Use the template in
[`../../specs/README.md`](../../specs/README.md): goal · scope · out of scope · design ·
files touched · verification.

A client spec should name the routes and components it adds, the API endpoints it
consumes, and any new `@devdigest/ui` primitive it needs.
