# specs — server

A spec per feature scoped to `@devdigest/api`, written **before** it is built. A feature
that also changes the client or the engine belongs in the root `../../specs/` instead.

Name files `NN-short-name.md`. Use the template in
[`../../specs/README.md`](../../specs/README.md): goal · scope · out of scope · design ·
files touched · verification.

A server spec should name the routes and modules it adds, whether it needs a migration,
and whether its tests are hermetic or `*.it.test.ts`.
